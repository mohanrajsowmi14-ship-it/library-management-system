# Library Management System

## Project Overview

This project is a Library Management System developed to manage books, users, reservations, overdue notifications, and monthly reports.

## Modules

- Book Search
- User Login
- Book Reservation
- Overdue Notifications
- Monthly Reports

## Git Workflow

Each module is developed in a separate branch. Changes are committed and submitted through Pull Requests. Team members review the changes before merging them into the main branch. Merge conflicts are resolved before completing the Pull Request.

## Branches

- book-search
- user-login
- book-reservation
- overdue-notification
- monthly-reports
